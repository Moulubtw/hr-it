# HR‑IT — AI‑тренажёр собеседований

Репетиция собеседования на любую вакансию. Вы вставляете вакансию и выбираете грейд, сложность и тон интервьюера. После каждого ответа ИИ показывает, как на этот вопрос ответил бы сильный кандидат, а в конце выдаёт отчёт.

**Сайт:** https://moulubtw.github.io/hr-it/

План проекта (PRD → SPEC → DESIGN): [PLAN.md](PLAN.md).

## Свой ключ Gemini

Каждый посетитель подключает **свой** API‑ключ Gemini в разделе «00 / Ключ Gemini» на странице настройки. Получить ключ можно в [Google AI Studio](https://aistudio.google.com/apikey).

- Ключ хранится только в браузере посетителя (`localStorage`) и отправляется напрямую в Google. У сайта нет сервера, поэтому ключ никуда больше не попадает.
- После проверки ключа сайт сам находит доступные модели:
  - основная — **Gemini 4 Hydrogen**, если она есть у ключа, иначе самая новая Pro;
  - резервные — Flash и Flash‑Lite.
  
  Модели можно поменять вручную в том же разделе.
- Удалить ключ можно кнопкой «Удалить ключ».

## Возможности

- **Грейды:** Стажёр, Junior, Middle, Senior, Team Lead.
- **Сложность:**
  - Щадящий — без таймера и уточнений;
  - Средний — 4 минуты на ответ и не больше одного уточнения подряд;
  - Сложный — 2,5 минуты на ответ и не больше двух уточнений подряд.
- **Тон HR:** Вежливый или Грубый. Грубый режим резкий, но без оскорблений: это задано в промпте и дополнительно проверяется на выходе.
- **После каждого ответа:**
  - реакция HR;
  - эталонный ответ: по методу STAR для поведенческих вопросов, по схеме «тезис → пример → итог» для остальных;
  - 1–3 пункта «что усилить» и оценка 0–10.
- **Итоговый отчёт:** оценки по критериям, сильные и слабые стороны, следующие шаги, полный ход интервью.
- **История в браузере:** повторы с теми же настройками нумеруются как «Дубль 01», «Дубль 02».

## Автопереключение моделей

Логика в [lib/ai/client.ts](lib/ai/client.ts):

| Ситуация | Что происходит |
|---|---|
| 429, 5xx, сетевая ошибка, нет первого токена за 12 с | переход к резервной модели, текущая отключается на 60 с (×2 при повторах, максимум 5 мин) |
| 404 или 403 (модели нет или нет доступа) | переход к резервной модели, текущая отключается сразу на 5 мин |
| неверный ключ, ошибочный запрос, отмена | остановка с понятным сообщением |
| обрыв посреди ответа | уже показанный текст сбрасывается, резервная модель отвечает с начала |

## Архитектура

Сайт полностью статический: Next.js `output: "export"`, хостинг на GitHub Pages.

- Всё интервью работает в браузере: промпты, переключение моделей, разбор потокового JSON и сессии.
- Сессии хранятся в `localStorage`, поэтому живут, пока посетитель не очистит данные браузера.
- **Стек:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, Zod, `@google/genai`, Vitest, Playwright.

## Локальный запуск

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:3000 и добавьте свой ключ на странице настройки.

## Проверки

```bash
npm run typecheck
```

```bash
npm run lint
```

```bash
npm test
```

```bash
npm run e2e
```

`npm run e2e` собирает статический сайт в демо‑режиме (заготовленные ответы, ключ не нужен) с префиксом `/hr-it`, как на GitHub Pages, и прогоняет сценарии на десктопе и в мобильной эмуляции. Перед первым запуском браузер нужно поставить командой `npx playwright install chromium`.

## Деплой

Каждый пуш в `main` запускает [.github/workflows/pages.yml](.github/workflows/pages.yml):

1. Проверка типов, линтер и юнит‑тесты.
2. Статическая сборка.
3. Публикация на GitHub Pages.

## Структура

```
app/                    страницы: /, /setup, /interview?id=…, /report?id=…
components/settings     панель «свой ключ Gemini»
components/setup        экран настройки
components/stage        сцена интервью: персонаж HR, таймер, ответ, разбор
components/report       отчёт
lib/ai                  клиент с переключением моделей, транспорт Gemini, демо-модель, промпты
lib/client              движок в браузере и настройки ключа
lib/session             логика интервью и хранилище сессий
e2e/                    Playwright-сценарии и мини-сервер, имитирующий GitHub Pages
```
